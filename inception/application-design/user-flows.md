# 유저 플로우 (User Flow)

> 사용자가 앱을 처음 설치하고 사용하는 전체 흐름입니다.

---

## Flow 1: 첫 설치 ~ 온보딩

```
[앱 설치]
    │
    ▼
[권한 요청 화면]
    "스마트폰 사용 기록 접근이 필요합니다"
    │
    ├── 허용 → [앱 분류 설정 화면]
    │           "자주 쓰는 앱을 분류해주세요"
    │           Instagram → 낭비
    │           YouTube → 낭비
    │           전자책 → 생산
    │           │
    │           ▼
    │         [PIN 설정 (선택)]
    │           "앱 잠금을 설정할까요?"
    │           │
    │           ▼
    │         [홈 대시보드]
    │           "Baseline 측정 중 (1일차/7일)"
    │           → 7일간 자동으로 평소 낭비시간 측정
    │
    └── 거부 → [재요청 안내]
               "이 권한 없이는 앱을 사용할 수 없습니다"
               [설정으로 이동] 버튼
```

---

## Flow 2: 일상 사용 (매일 반복)

```
[앱 실행]
    │
    ├── PIN 설정됨 → [PIN 입력] → 성공 → [홈]
    │                             실패 5회 → 30초 잠금
    │
    └── PIN 없음 → [홈 대시보드]
                    │
                    ├── "오늘 낭비 2h 10m" 확인
                    ├── "평소보다 50m 적음" 확인
                    └── 미확인 충돌 3건 배지 탭
                            │
                            ▼
                         [충돌 확인 팝업]
                          "공부 중 YouTube 45분 사용"
                          ├── 강의 목적 → PRODUCTIVE
                          ├── 보조적 → MIXED
                          ├── 딴짓 → WASTE
                          ├── 휴식 → LEISURE
                          └── 기타 → NEUTRAL
```

---

## Flow 3: 시간 되찾기 (타이머)

```
[되찾기 탭]
    │
    ▼
[목표 목록]
    💻 개발   ▶
    📖 공부   ▶
    🏃 운동   ▶
    📚 독서   ▶
    │
    ▼ (개발 ▶ 탭)
[타이머 시작]
    "개발 진행 중..."
    00:00:00 → 카운트 시작
    (앱 벗어나도 백그라운드 계속 동작)
    │
    ├── ⏹ 종료 버튼
    │     │
    │     ├── 1분 이상 → "개발 +42m 기록됨!" 토스트
    │     │               목표 누적시간에 합산
    │     │
    │     └── 1분 미만 → 기록 안 함
    │
    └── 취소 → 기록 안 함
```

---

## Flow 4: 활동 직접 기록 (수동)

```
[되찾기 탭] → [활동 직접 기록] 버튼
    │
    ▼
[기록 입력 화면]
    목표 선택: [운동 ▼]
    시작 시간: [19:00]
    종료 시간: [20:00]
    │
    ▼ [저장]
    │
    ├── RecoveredTime 생성 (method=MANUAL, 60분)
    ├── Activity 동시 생성 (RUNNING, 19:00~20:00)
    │     → 해당 시간대 Context 재분석 트리거
    │     → 19:05~19:55 YouTube = "운동 중 시청" (MIXED)
    │
    └── "운동 +60m 기록됨!" 토스트
```

---

## Flow 5: Timeline 확인 및 수정

```
[Timeline 탭]
    │
    ▼
[날짜 선택] ← → 스와이프
    │
    ▼
[시간대별 타임라인]
    13:00 Instagram 32m 🔴낭비
    16:00 YouTube 35m 🔴낭비
    19:00 운동 1h
      └── YouTube 50m 🔵운동 중 시청
    21:00 개발 1h 🟢생산
    23:00 Instagram 40m 🔴낭비
    │
    ▼ (항목 탭)
[분류 변경 바텀시트]
    현재: 낭비
    변경: [생산] [여가] [낭비] [혼합] [중립]
    │
    ▼ (선택)
    분류 변경됨 → 낭비시간 재계산
```

---

## Flow 6: 주간 리포트

```
[매주 일요일 21:00]
    │
    ▼
[자동 리포트 생성]
    │
    ▼
[푸시 알림] "이번 주 리포트가 준비됐습니다"
    │
    ▼ (알림 탭)
[리포트 화면]
    이번 주 낭비: 11h 20m
    Baseline: 16h 20m
    확보: 5h
    되찾음: 개발 2h + 운동 1h + 공부 1h = 4h
    회수율: 80%
```

---

## Flow 7: Baseline 완성

```
[7일 경과]
    │
    ▼
[자동 Baseline 생성]
    "7일간 주간 낭비시간: 16h 20m"
    │
    ▼
[홈 대시보드 변경]
    "측정 중" → "Baseline: 16h 20m"
    확보시간/회수율 표시 시작
```

---

## 전체 흐름 한눈에

```
설치 → 권한 → 분류설정 → (7일 측정) → Baseline 확정
                                              │
                    ┌───────────────────────────┘
                    ▼
              [매일 반복]
              ┌─────────────────────────────────┐
              │                                 │
              │  자동: 앱 사용 수집 → 세션 생성  │
              │  수동: 활동 기록 / 타이머        │
              │         ↓                       │
              │  Context 분석 → 낭비 판정       │
              │         ↓                       │
              │  대시보드 갱신                   │
              │  충돌 있으면 → 질문              │
              │                                 │
              └─────────────────────────────────┘
                    │
                    ▼ (매주 일요일)
              [주간 리포트 생성 + 알림]
```
