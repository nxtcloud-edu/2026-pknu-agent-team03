## 프로토타입 실행

실제 동작하는 HTML 프로토타입이 있습니다:

```
파일: src/prototype/index.html
실행: 브라우저에서 열기
```

- 하단 네비게이션 탭 전환
- 타이머 실제 동작 (▶ 시작 / ⏹ 정지)
- 오늘 기록 실시간 표시
