# User Stories

## Epic 1: 앱 사용 데이터 수집 (FR-1)

### US-1.1: 사용 권한 허가
- **As a** 사용자
- **I want** 앱 설치 후 UsageStatsManager 권한을 쉽게 허가할 수 있기를
- **So that** 앱이 내 스마트폰 사용 데이터를 수집할 수 있다
- **Acceptance Criteria**:
  - [ ] 권한 미허가 시 설정 화면으로 안내하는 UI가 표시된다
  - [ ] 권한 허가 상태를 앱 진입 시마다 확인한다
  - [ ] 권한이 해제되면 데이터 수집이 중단되고 사용자에게 알린다
- **Priority**: MVP Must

### US-1.2: 앱 세션 재구성
- **As a** 사용자
- **I want** 내 앱 사용 기록이 자동으로 세션 단위로 정리되기를
- **So that** 언제 어떤 앱을 얼마나 사용했는지 한눈에 볼 수 있다
- **Acceptance Criteria**:
  - [ ] Foreground/Background 이벤트 기반으로 세션(시작~종료, 지속시간)이 생성된다
  - [ ] 하루치 이벤트를 3초 이내에 처리한다
  - [ ] 세션 데이터가 서버에 동기화된다
- **Priority**: MVP Must

---

## Epic 2: 앱 분류 관리 (FR-2)

### US-2.1: 앱 기본 분류 설정
- **As a** 사용자
- **I want** 내 앱들의 기본 분류(생산/여가/낭비/중립)를 설정할 수 있기를
- **So that** 시스템이 Context 없이도 기본적인 시간 판정을 할 수 있다
- **Acceptance Criteria**:
  - [ ] 설치된 앱 목록이 표시된다
  - [ ] 각 앱에 4개 분류 중 하나를 지정할 수 있다
  - [ ] 기본값은 '중립'이다
  - [ ] 설정은 언제든 변경 가능하다
- **Priority**: MVP Must

---

## Epic 3: 활동 기록 (FR-3)

### US-3.1: 오프라인 활동 직접 기록
- **As a** 민준 (대학생)
- **I want** 내가 한 활동(공부, 운동 등)을 시작/종료 시간과 함께 직접 기록할 수 있기를
- **So that** 시스템이 해당 시간대의 앱 사용을 맥락적으로 판단할 수 있다
- **Acceptance Criteria**:
  - [ ] 활동 유형(운동, 공부, 개발, 독서, 여가, 커스텀)을 선택할 수 있다
  - [ ] 시작 시간과 종료 시간을 입력할 수 있다
  - [ ] 기록된 활동이 Timeline에 표시된다
  - [ ] 기록된 활동이 해당 시간대의 앱 세션과 Context 분석에 활용된다
- **Priority**: MVP Must

---

## Epic 4: Context 기반 시간 판정 (FR-4, FR-5)

### US-4.1: 시간 중첩 분석
- **As a** 준호 (자기계발 추구자)
- **I want** 운동 중 YouTube를 본 시간이 자동으로 '운동 중 시청'으로 인식되기를
- **So that** 복합 활동이 낭비로 잘못 분류되지 않는다
- **Acceptance Criteria**:
  - [ ] 활동 기록과 앱 세션의 시간 중첩을 자동 감지한다
  - [ ] 겹치는 앱 세션은 기본 분류가 아닌 Context로 처리된다
  - [ ] 복합 활동 시간이 실제 경과시간을 초과하지 않는다
- **Priority**: MVP Must

### US-4.2: 활동 충돌 확인
- **As a** 민준 (대학생)
- **I want** 공부 시간에 YouTube를 많이 사용했을 때 시스템이 무엇을 했는지 물어봐 주기를
- **So that** 강의 시청인지 딴짓인지 정확하게 분류할 수 있다
- **Acceptance Criteria**:
  - [ ] 활동과 앱 사용이 충돌할 때 선택지(강의/보조/딴짓/휴식/기타)를 제시한다
  - [ ] 사용자 응답에 따라 최종 분류가 결정된다
  - [ ] 응답하지 않으면 기본 분류가 적용된다
- **Priority**: MVP Must

### US-4.3: 분류 수정
- **As a** 사용자
- **I want** Timeline에서 잘못 분류된 시간을 직접 수정할 수 있기를
- **So that** 시스템의 판단이 틀렸을 때 바로잡을 수 있다
- **Acceptance Criteria**:
  - [ ] Timeline의 각 항목에서 분류를 변경할 수 있다
  - [ ] 수정 시 낭비시간과 관련 통계가 즉시 재계산된다
- **Priority**: MVP Must

---

## Epic 5: 낭비시간 및 Baseline (FR-6, FR-7)

### US-5.1: 낭비시간 확인
- **As a** 서연 (직장인)
- **I want** 오늘/이번 주 낭비한 시간을 한눈에 볼 수 있기를
- **So that** 내가 얼마나 시간을 흘려보내고 있는지 인식할 수 있다
- **Acceptance Criteria**:
  - [ ] WASTE로 분류된 세션의 합계를 일별/주별로 표시한다
  - [ ] 시간대별로 어느 앱이 얼마나 낭비인지 상세 확인 가능하다
- **Priority**: MVP Must

### US-5.2: Baseline 생성
- **As a** 신규 사용자
- **I want** 처음 7일간 자동으로 내 평소 낭비시간이 측정되기를
- **So that** 이후 개선 정도를 비교할 기준점이 생긴다
- **Acceptance Criteria**:
  - [ ] 가입 후 7일간 데이터를 수집하여 주간 평균 낭비시간을 계산한다
  - [ ] Baseline 측정 중임을 사용자에게 안내한다
  - [ ] 7일 후 Baseline이 확정되고 대시보드에 비교 데이터가 표시된다
- **Priority**: MVP Must

### US-5.3: 확보한 시간
- **As a** 서연 (직장인)
- **I want** Baseline 대비 내가 줄인 낭비시간(확보한 시간)을 볼 수 있기를
- **So that** 개선하고 있다는 동기부여를 받을 수 있다
- **Acceptance Criteria**:
  - [ ] 이번 주 낭비시간과 Baseline의 차이를 '확보한 시간'으로 표시한다
  - [ ] 확보한 시간이 음수(더 낭비)일 경우에도 명확히 표시한다
- **Priority**: MVP Must

## Epic 6: 목표 관리 (FR-8)

### US-6.1: 목표 등록
- **As a** 준호 (자기계발 추구자)
- **I want** 여러 목표(개발, 운동, 독서 등)를 등록하고 각각 목표시간을 설정할 수 있기를
- **So that** 각 분야에 투자하고 싶은 시간을 체계적으로 관리할 수 있다
- **Acceptance Criteria**:
  - [ ] 목표 이름과 목표시간을 입력하여 등록할 수 있다
  - [ ] 등록된 목표의 누적 투자시간과 진행률을 조회할 수 있다
  - [ ] 목표를 수정/삭제할 수 있다
- **Priority**: MVP Must

---

## Epic 7: 시간 되찾기 (FR-9, FR-10)

### US-7.1: 타이머로 시간 되찾기
- **As a** 민준 (대학생)
- **I want** 목표를 선택하고 타이머를 켜서 활동을 시작할 수 있기를
- **So that** 되찾은 시간이 자동으로 기록되고 목표에 누적된다
- **Acceptance Criteria**:
  - [ ] 목표 활동을 선택하고 타이머를 시작할 수 있다
  - [ ] 타이머 완료 시 해당 시간이 되찾은 시간으로 기록된다
  - [ ] 기록된 시간이 해당 목표의 누적시간에 합산된다
- **Priority**: MVP Must

### US-7.2: 수동으로 되찾은 시간 기록
- **As a** 사용자
- **I want** 타이머 없이도 이미 완료한 활동을 수동으로 되찾은 시간에 등록할 수 있기를
- **So that** 타이머를 깜빡 잊었을 때도 기록을 남길 수 있다
- **Acceptance Criteria**:
  - [ ] 목표, 시작/종료 시간을 입력하여 수동 기록할 수 있다
  - [ ] 수동 기록도 되찾은 시간과 회수율에 반영된다
- **Priority**: MVP Must

### US-7.3: 시간 회수율 확인
- **As a** 서연 (직장인)
- **I want** 확보한 시간 중 실제 활동으로 전환한 비율(회수율)을 볼 수 있기를
- **So that** 단순히 줄이는 것뿐 아니라 실제로 활용하고 있는지 확인할 수 있다
- **Acceptance Criteria**:
  - [ ] 회수율 = 되찾은 시간 / 확보한 시간 × 100으로 계산된다
  - [ ] 대시보드에 퍼센트로 표시된다
- **Priority**: MVP Must

---

## Epic 8: 대시보드 및 화면 (FR-11, FR-12)

### US-8.1: 메인 대시보드
- **As a** 사용자
- **I want** 앱을 열면 오늘의 핵심 수치(낭비, 확보, 되찾음, 회수율)를 바로 볼 수 있기를
- **So that** 복잡한 데이터 없이 현재 상태를 직관적으로 파악할 수 있다
- **Acceptance Criteria**:
  - [ ] 오늘 낭비시간, Baseline 대비 증감, 되찾은 시간을 표시한다
  - [ ] 이번 주 낭비, 확보, 되찾음, 회수율을 표시한다
  - [ ] 현재 목표 진행도를 표시한다
  - [ ] 앱 실행 후 2초 이내에 데이터를 로드한다
- **Priority**: MVP Must

### US-8.2: Timeline 화면
- **As a** 사용자
- **I want** 하루의 시간 사용을 시간대별로 시각적으로 볼 수 있기를
- **So that** 언제 무엇을 했고, 어느 시간이 낭비였는지 직관적으로 파악할 수 있다
- **Acceptance Criteria**:
  - [ ] 시간대별 앱 사용, 활동, 복합 활동이 타임라인 형태로 표시된다
  - [ ] 각 항목에 낭비(빨강)/생산(초록)/여가(회색) 표시가 있다
  - [ ] 항목을 탭하여 분류를 수정할 수 있다
- **Priority**: MVP Must

## Epic 9: 주간 리포트 (FR-13)

### US-9.1: 주간 리포트 생성 및 알림
- **As a** 사용자
- **I want** 매주 시간 사용 결과를 요약한 리포트를 받을 수 있기를
- **So that** 한 주간의 개선 정도를 종합적으로 확인할 수 있다
- **Acceptance Criteria**:
  - [ ] 매주 낭비시간, Baseline 비교, 확보시간, 목표별 되찾은 시간, 회수율을 포함한다
  - [ ] 리포트 생성 시 푸시 알림으로 안내한다
  - [ ] 앱 내에서 과거 리포트를 다시 조회할 수 있다
- **Priority**: MVP Must

## Epic 10: 실시간 알림 (FR-14)

### US-10.1: 낭비 경고 알림
- **As a** 민준 (대학생)
- **I want** 낭비 시간이 임계치를 넘으면 알림을 받을 수 있기를
- **So that** 무의식적으로 시간을 낭비하고 있다는 것을 즉시 인식할 수 있다
- **Acceptance Criteria**:
  - [ ] 낭비 시간 임계치를 사용자가 설정할 수 있다
  - [ ] 임계치 초과 시 푸시 알림이 발송된다
  - [ ] 알림에서 바로 앱으로 이동할 수 있다
- **Priority**: MVP Should

## Epic 11: 인증 (FR-15)

### US-11.1: 로컬 PIN 보호
- **As a** 사용자
- **I want** 앱에 PIN을 설정하여 다른 사람이 내 데이터를 보지 못하게 할 수 있기를
- **So that** 개인 사용 패턴이 보호된다
- **Acceptance Criteria**:
  - [ ] 4~6자리 PIN을 설정/변경/해제할 수 있다
  - [ ] PIN은 해시 처리하여 저장한다
  - [ ] 앱 진입 시 PIN 입력을 요구한다 (설정된 경우)
- **Priority**: MVP Should
