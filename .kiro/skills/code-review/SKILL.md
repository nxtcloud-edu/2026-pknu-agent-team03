# TimeBack 코드 리뷰 Skill

## 절차

1. 변경 diff와 관련 FR/NFR, 승인된 기능 설계·기술 결정을 찾는다.
2. 승인되지 않은 구현, MVP 제외 기능, 문서 폴더의 실행 코드를 확인한다.
3. 시간 관련 변경에는 `timeback-temporal-domain`의 불변식을 적용한다.
4. UsageStats·권한·저장·전송·로그 변경에는 `timeback-privacy-review`를 적용한다.
5. 사용자 확정 Context 우선순위와 실제 경과시간 중복 집계 금지를 확인한다.
6. 오류·취소·권한 철회·데이터 삭제 경로와 민감 로그 노출을 확인한다.
7. 관련 테스트가 요구사항 경계를 검증하며 합성 데이터만 사용하는지 확인한다.
8. 실행된 명령과 실제 결과를 확인하고, 실행하지 못한 검증은 한계로 표시한다.

## 출력

- 심각도순 findings: 파일·위치, 재현 조건, 영향, 근거, 최소 수정 방향
- 확인이 필요한 가정과 미검증 영역
- 관련 FR/NFR 및 설계 문서
- findings가 없을 때도 남은 검증 위험

스타일 선호보다 정확성, 개인정보, 데이터 손실, 추적성 문제를 우선한다.
