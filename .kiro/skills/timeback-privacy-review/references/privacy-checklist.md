# TimeBack 개인정보 검토 체크리스트

## 데이터 최소화

- [ ] 각 필드가 특정 FR에 필요하다.
- [ ] 원본 이벤트 대신 파생 세션/집계만 보존할 수 있는지 검토했다.
- [ ] 불필요한 영구 사용자 식별자를 만들지 않았다.
- [ ] 화면 내용, 위치, 입력 내용은 수집하지 않는다.

## 투명성과 통제

- [ ] Usage Access 목적과 제한을 권한 설정 전에 설명한다.
- [ ] 권한 미부여·철회 시 동작이 정의되어 있다.
- [ ] 사용자가 Context를 확인·수정할 수 있다.
- [ ] 데이터 삭제·초기화 방법이 정의되어 있다.

## 저장과 보존

- [ ] 원본 이벤트와 파생 데이터의 보존기간이 구분되어 있다.
- [ ] 백업 포함 여부를 확인했다.
- [ ] 기기 공유와 잠금 해제 상태의 노출을 고려했다.
- [ ] 민감 데이터를 로그·예외 메시지에 넣지 않는다.

## 외부 연결

- [ ] 네트워크 전송 필드와 목적이 명시되어 있다.
- [ ] 분석/광고/크래시 SDK가 자동 수집하는 항목을 확인했다.
- [ ] 외부 전송은 최소 수집·명시 동의·삭제 정책을 가진다.
- [ ] 프로젝트 코드나 실제 사용자 데이터를 검토 목적으로 외부에 전송하지 않는다.

## Android 표면

- [ ] Manifest 권한이 최소이다.
- [ ] exported 컴포넌트가 명시적이고 필요한 것만 노출된다.
- [ ] intent 입력과 파일 공유 경로를 검증한다.
- [ ] 디버그 전용 기능이 릴리스에 포함되지 않는다.
