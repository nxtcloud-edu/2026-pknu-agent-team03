# 시간 도메인 불변식과 사례

## 불변식

1. 모든 유효 구간은 `start < end`이다.
2. 지속시간은 음수가 아니다.
3. 하루 집계의 원자 시간 구간은 서로 겹치지 않는다.
4. Context 합계는 분석 대상 실제 경과시간보다 크지 않다.
5. 사용자 확정 분류는 자동 분류보다 우선한다.
6. 동일 원본 이벤트에서 파생된 세션을 중복 집계하지 않는다.
7. Saved Time과 Recovery Rate의 경계는 승인된 정책을 따른다.

## TimeBack 대표 사례

### 운동 중 YouTube

- Activity: 운동 19:00–20:00
- AppSession: YouTube 19:05–19:55
- 실제 경과 범위: 60분
- 결과: 운동 60분의 Context 안에 YouTube 사용 근거를 연결하며 총 110분으로 집계하지 않는다.

### 부분 중첩

- Activity: 공부 20:00–21:00
- AppSession: YouTube 20:40–21:20
- 원자 구간:
  - 20:00–20:40 공부
  - 20:40–21:00 충돌 Context
  - 21:00–21:20 YouTube Default Context

### 이벤트 누락

- YouTube Foreground 19:00
- 종료 이벤트 없음
- 승인된 추정 규칙 없이는 임의의 장시간 세션으로 확정하지 않는다. 추정 여부와 근거를 보존한다.

## 계산 경계 테스트

- Baseline 없음 / 유효일 부족
- Baseline = 현재 낭비시간
- 현재 낭비시간 > Baseline
- Saved Time = 0, Recovered Time = 0
- Saved Time = 0, Recovered Time > 0
- Recovered Time > Saved Time
- 사용자 시간대 변경과 DST 전환
