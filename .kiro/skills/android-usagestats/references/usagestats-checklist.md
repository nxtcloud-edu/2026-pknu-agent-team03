# UsageStats 구현 체크리스트

## 권한과 UX

- [ ] Usage Access 허용 여부를 실제 시스템 상태로 확인한다.
- [ ] 설정 화면 진입 전 수집 목적을 설명한다.
- [ ] 사용자가 돌아왔을 때 상태를 다시 확인한다.
- [ ] 미부여·철회 상태에서도 앱이 정상 동작한다.

## 수집

- [ ] 조회 시작·종료 시각과 시간 단위가 명확하다.
- [ ] 빈 결과를 정상 상태로 처리한다.
- [ ] 동일 구간 재조회 시 중복 제거가 가능하다.
- [ ] 마지막 수집 지점 손실을 막기 위한 overlap 정책이 있다.
- [ ] 지원하지 않는 이벤트 타입을 안전하게 무시하거나 관찰한다.

## 세션화 경계

- [ ] Android `UsageEvents.Event`를 도메인 밖에서 직접 사용하지 않는다.
- [ ] Foreground/Background 누락과 중복을 처리한다.
- [ ] 앱 전환을 단순한 단일 포그라운드 가정으로만 처리하지 않는다.
- [ ] 화면 꺼짐, 재부팅, 자정 경계를 검토한다.
- [ ] 추정 세션에는 추정 여부와 근거가 있다.

## 개인정보

- [ ] 상세 package name과 timestamp를 운영 로그에 남기지 않는다.
- [ ] 원본 이벤트 보존기간이 정의되어 있다.
- [ ] 외부 전송이 기본적으로 없다.
- [ ] 삭제·초기화 정책과 일치한다.

## 검증 fixture

- [ ] 정상 한 세션
- [ ] 여러 앱 전환
- [ ] 종료 누락
- [ ] 시작 누락
- [ ] 중복 이벤트
- [ ] 동일 timestamp
- [ ] 자정 통과
- [ ] 권한 미부여와 빈 결과
