# 요구사항 추적 체크리스트

## 원문 보존

- [ ] 최신 사용자 요구가 `spec.md` 끝에 원문 그대로 존재한다.
- [ ] 기존 원문을 수정·요약·재배치하지 않았다.
- [ ] 잘리거나 손상된 입력을 추정하지 않고 미확정으로 표시했다.

## FR 품질

- [ ] FR마다 사용자 또는 시스템의 관찰 가능한 동작이 있다.
- [ ] 하나의 FR에 여러 독립 기능을 과도하게 묶지 않았다.
- [ ] FR이 원문 절 또는 승인 답변으로 추적된다.
- [ ] 자동 판정과 사용자 수정의 우선순위가 명확하다.

## NFR 품질

- [ ] Correctness에 시간 중복 집계 금지가 있다.
- [ ] Testing에 중첩·자정·누락 이벤트 경계가 있다.
- [ ] Privacy에 최소 수집·권한 철회·외부 전송 조건이 있다.
- [ ] Maintainability에 Android API와 도메인 계산 분리가 있다.
- [ ] 미확정 수치를 임의의 고정값으로 만들지 않았다.

## 범위

- [ ] MVP 필수 기능이 원문 25번과 일치한다.
- [ ] 반복 Context, 추천, 패턴 분석 등 2차 기능이 MVP에서 제외됐다.
- [ ] iOS, 화면 감시, 위치 추적, 콘텐츠 자동 판별이 제외됐다.
- [ ] 범위 변경은 새 원문과 승인을 가진다.
