# TimeBack AI-DLC 단계 게이트 Skill

## 시작 조건

1. 루트 `spec.md`, `aidlc-state.md`, `aidlc-docs/audit.md`, `aidlc-docs/mistakes.md` 존재 여부를 확인한다.
2. 필수 기록이 없거나 현재 산출물과 상태가 다르면 단계를 추정하지 않는다.
3. 누락·불일치를 객관적으로 보고하고 복구 방법에 대한 사용자 결정을 먼저 받는다.
4. 기존 `spec.md`, `audit.md`, `mistakes.md`는 append-only로만 다룬다.

## 단계 진행

1. `aidlc-state.md`에서 활성 단계, 작업 단위, 게이트 상태를 읽는다.
2. 최신 요청이 `spec.md`에 원문 그대로 추가됐는지 확인한다.
3. 현재 단계의 입력과 선행 Gate 2 승인을 확인한다.
4. 계획과 검증 질문만 작성하고 다음 선택지로 Gate 1을 요청한다.
   - `1) 수정 요청`
   - `2) 다음 단계로`
5. Gate 1 승인 전에는 본 산출물이나 애플리케이션 코드를 생성하지 않는다.
6. 승인 후 지정된 `aidlc-docs/` 경로에 현재 단계 산출물만 만든다.
7. 산출물, 원문 근거, 검증 결과, 미확정 사항을 대조한다.
8. 같은 두 선택지로 Gate 2를 요청한다.
9. Gate 2 승인 후에만 audit를 append하고 state를 다음 단계로 갱신한다.

## 복구 규칙

- `spec.md`가 없으면 기존 문서에서 원문을 역추정하지 않는다.
- 비표준 경로의 기존 산출물은 사용자 승인 없이 이동·재분류하지 않는다.
- 문서 내부 체크 표시만으로 게이트 승인을 확정하지 않는다.
- 누락된 과거 답변이나 날짜를 만들어내지 않는다.
- 절차 위반 또는 수정 요청은 `mistakes.md`에 append할 내용을 제안하고 승인 후 기록한다.

## 완료 보고

현재 단계, 확인한 근거, 생성·변경 파일, Gate 상태, 실행한 검증, 다음에 필요한 사람의 결정을 구분해 보고한다.
