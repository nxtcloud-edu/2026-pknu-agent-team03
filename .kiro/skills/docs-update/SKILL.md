# TimeBack 문서 갱신 Skill

## 절차

1. `aidlc-state.md`와 대상 단계의 승인 상태를 확인한다.
2. 사용자의 최신 원문이 `spec.md`에 그대로 보존됐는지 확인한다.
3. 대상 문서의 공식 `aidlc-docs/` 경로와 기존 내용을 확인한다.
4. 원문에 없는 요구, 기술, 수치, 정책을 추가하지 않는다.
5. 기존 식별자(FR/NFR/US/구성 요소/UOW)와 용어를 유지한다.
6. 변경된 항목의 상·하위 추적 관계와 MVP 경계를 점검한다.
7. `spec.md`, `audit.md`, `mistakes.md`에는 append만 사용한다.
8. 링크, 중복 ID, 미확정 항목, 실제 파일 위치를 검증한다.
9. 변경 근거와 검증 결과를 보고하고 현재 단계의 Gate 규칙을 따른다.

## 금지

- 누락된 원문 또는 게이트 답변 추정
- 비표준 경로의 기존 문서를 승인 없이 이동
- Inception에서 기술 스택 확정
- 실제 코드를 문서 폴더에 저장
- MVP 제외 기능을 승인 없이 요구사항에 혼입
