# TimeBack 테스트 정책

## 테스트 피라미드

- 시간 계산, 세션화, 중첩, Context 우선순위는 Android 프레임워크와 분리된 빠른 단위 테스트로 검증한다.
- UsageStats 어댑터, 저장소, 권한 흐름은 fake 입력과 통합 테스트로 검증한다.
- 핵심 사용자 흐름만 UI/기기 테스트로 검증한다.

## 필수 경계 사례

- 정상 Foreground → Background 세션
- Background 누락, 중복 Foreground, 역순 이벤트
- 앱 전환, 화면 꺼짐, 재부팅 경계
- 중첩 없음, 경계 접촉, 부분 중첩, 완전 포함, 동일 구간, 다중 중첩
- 자정 통과와 시간대/DST 변경
- 사용자 수정 Context가 재분석 후에도 유지됨
- Baseline 데이터 부족, 현재 낭비 증가, Saved Time 0
- Recovered Time 0 및 Saved Time보다 큰 경우
- Usage Access 미부여·철회

## 작성 규칙

- 테스트 이름은 조건과 기대 결과를 드러낸다.
- 현재 구현을 복제하지 말고 요구사항의 불변식을 검증한다.
- 조정 수치가 바뀌어도 도메인 불변식 테스트가 깨지지 않게 분리한다.
- 실제 사용자 앱 목록이나 행동 데이터 대신 합성 fixture를 사용한다.
- 실패를 무시하거나 테스트를 삭제해 통과시키지 않는다.

## 완료 기준

변경된 FR/NFR에 대응하는 테스트, 실행 명령, 실제 결과가 있어야 완료로 보고할 수 있다. 전체 Android 빌드가 준비되지 않았다면 실행하지 못한 이유와 대체 검증을 명시한다.
