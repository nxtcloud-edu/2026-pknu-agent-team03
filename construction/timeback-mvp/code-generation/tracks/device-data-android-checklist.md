# track-device-data Android 14 이상 실기기 체크리스트

## 현재 상태

- 확인일: 2026-08-26
- `adb devices -l`: 연결 기기 없음
- 판정: NFR-3.3 미완료, 아래 결과 기록 전 통과 표시 금지

## 준비

- Android 14(API 34) 이상 실제 기기 한 대
- 네 트랙을 통합한 디버그 빌드
- 테스트 전 앱의 Usage Access를 해제하고 테스트 사용자 데이터 초기화
- 실제 패키지명·시각만 최소한으로 기록하고 화면 내용·앱 내부 콘텐츠는 캡처하지 않음

## 시나리오

| ID | 절차 | 기대 결과 | 결과 |
|---|---|---|---|
| `DEVICE-ACCESS-01` | Usage Access 미허용 상태로 앱 실행 | UI-01 차단, UsageStats 조회·신규 저장 없음 | 미실행 |
| `DEVICE-ACCESS-02` | 설정 열기 → 권한 허용 → 앱 복귀 | 복귀 후 재조회에서만 `GRANTED`, 주요 화면 진입 가능 | 미실행 |
| `DEVICE-COLLECT-01` | 앱 A 실행 → 앱 B 전환 → 앱 복귀·새로고침 | 허용 사건만 수집, A가 B 시작 시각 이전의 유효 근거로 닫힘 | 미실행 |
| `DEVICE-SESSION-01` | 앱 A 사용 중 화면 끄기 → 앱 복귀 | 열린 A가 실제 화면 종료 사건으로 닫힘 | 미실행 |
| `DEVICE-ACCESS-03` | 사용 중 설정에서 Usage Access 회수 → 앱 복귀 | 다음 보호 작업부터 즉시 차단, 기존 로컬 데이터는 유지 | 미실행 |
| `DEVICE-PRIVACY-01` | 저장 레코드·디버그 로그 검사 | 패키지명·사건 종류·발생 시각 외 화면 내용·콘텐츠·위치 없음 | 미실행 |
| `DEVICE-PERF-01` | 새 사건 생성 후 앱 새로고침 5회 | 전체 Timeline·대시보드 5초 이내, device-data 구간 4초 이내 | 미실행 |
